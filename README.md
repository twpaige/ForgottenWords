# Crown & Call public references

This repository publishes the website at https://crownandcall.com.

- The existing root rules pages govern **C&C TTRPG**.
- [CCMud/WORK_START_HERE.md](CCMud/WORK_START_HERE.md) is the entry point for the separate **C&C MUD** knowledge base, published at https://crownandcall.com/CCMud/.
- MUD implementation belongs to private `twpaige/Crown-Call`. No MUD code is published here by the documentation process.

CCMud Markdown is converted automatically by GitHub Pages/Jekyll on pushes to `main`. Existing HTML pages remain static. See [publishing](CCMud/PUBLISHING.md) for layout, source ownership, verification, and private reference synchronization.
